# System: Rappelling

**Version:** v1.0.2

## Purpose
Execute conservative rappels with mandatory backups.

## Required gear
- Tube device (Reverso/Verso)
- HMS locker
- **Autoblock cord**
- Helmet

## Rules
### 7.3 Rappelling
- Autoblock below device.
- Knots in rope ends when length uncertain.
