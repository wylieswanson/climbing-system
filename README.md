# Climbing System (Wylie + Lorena)

Private, versioned **personal operating manual** for our outdoor climbing gear, racking, systems, and safety doctrine.

## Start here
- **Index:** [docs/00_index.md](docs/00_index.md)

## How we use this repo
- Use **docs/06_checklists.md** at the car / trailhead.
- Use **docs/05_systems/** when practicing or teaching specific systems.
- Log incidents in **incidents/incident-log.md**.
- Update inventory in **inventory/inventory-audit.csv** and mirror updates in **docs/02_inventory.md**.

## Versioning
- Patch: inventory/config changes
- Minor: system-flow changes
- Major: doctrine/scope changes
